Core Philosophy

Refusal is the product.

The market is flooded with agents that hallucinate triumph. They encounter an API failure, swallow the error, and declare "Done!" with confident prose. Done takes the opposite stance: an agent's true value lies in its honesty.

Promises vs. Receipts

Other agents generate conversational claims. Done generates cryptographically auditable receipts. If a command exits with code 9009 (file not found), the receipt says exit 9009. It never pretends a missing runtime succeeded.

Zero Unprompted Collateral

Before sending an email, dropping a table, or running an irreversible git push, Done stops and halts. It generates a bespoke decision card explaining the exact consequence, awaiting human confirmation.

Dual-Layer Defense

Screening every byte before it reaches the brain.

Get Started

Launch locally in under two minutes.

Clone the repository, configure your environment variables, and boot the Electron desktop application or run the headless verification harness. 

# 1. Clone repository
git clone https://github.com/0dvsh0/done.git
cd done/desktop-app

# 2. Install dependencies
npm install

# 3. Configure credentials in .env
echo "LLM_API_KEY=gsk_your_groq_key" > ../.env
echo "NEATLOGS_API_KEY=your_neatlogs_key" >> ../.env

# 4. Launch Desktop App
npm run dev
